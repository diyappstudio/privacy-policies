Permission scope

READ_SMS supports backup, comparison and readback. Backup works while the user's usual messenger remains default. Android requires temporary SMS-role access to write restored rows; RECEIVE_SMS, RECEIVE_MMS and RECEIVE_WAP_PUSH preserve incoming data during that access. SEND_SMS is absent from the code 8 manifest; there is no carrier sending or composer. Android's SMS group and role dialogs use generic system wording. Restoring sent-history records writes history only and never retransmits messages.

Reproduce on an empty review device

  1. No account, login, payment or subscription is required. Set any device screen-lock PIN if using the protected preview.
  2. Download the XML fixture above. Open SMS Restore → Restore from a backup → choose the XML → unlock preview with your own device credential.
  3. Select messages → Review selection → grant SMS read access if asked → Restore selected SMS → choose temporary SMS Restore access in Android.
  4. Check Added and verified. Use Return to my SMS app and choose your usual messenger.
  5. Create a backup of the restored SMS: choose a folder and your own password of at least 12 characters, then Create backup. The saved archive is reopened and verified.

The fixture contains 3 fictional messages. Device SMS are kept; existing messages are not deleted and repeated restoration skips duplicates. The app backs up/restores SMS text history; MMS attachments, RCS, chats and call logs are outside this backup format.
